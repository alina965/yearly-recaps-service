# My Contribution: Avito Yearly Recaps

Этот репозиторий содержит выбранные файлы проекта, над которыми я работала большую часть времени.

## Что я реализовала

### 1) Рекомендованные действия (Recap Actions)
- Переработала логику выбора action в backend на основе метрик и score-подхода.
- Добавила более гибкий выбор между сценариями (`boost_listings`, `create_listing`, `listing_abandoned`, `compare_top`, `open_favorites`, `continue_search`).
- Улучшила формирование `target` для action, включая данные по объявлениям.

### 2) Обогащение данных объявлений
- Расширила backend-структуры и сбор данных, чтобы на frontend приходили:
  - название объявления,
  - категория и название категории,
  - цена,
  - картинка,
  - город,
  - просмотры,
  - статус и дата обновления.
- Обновила DTO и маппинг ответа recap.

### 3) UI модалок действий на frontend
- Сделала модалки для action-сценариев с единым UX.
- Добавила и доработала таблицу сравнения top-3.
- Привела тексты и стили к единообразию (включая демонстрационные подписи и кнопки).
- Убрала лишние внешние переходы и привела отображение данных к актуальному API.

### 4) Тестовые данные и медиа
- Обновила seed-данные для более реалистичных профилей и разнообразных action-сценариев.
- Синхронизировала пути изображений объявлений с локальными статическими файлами.

### 5) Поддержка качества
- Актуализировала тесты backend после изменений в сигнатурах и логике выбора action.
- Исправила lint-замечания на frontend.

## Технический стек
- Backend: Go
- Frontend: React + TypeScript
- База данных: PostgreSQL
- Локальная инфраструктура: Docker Compose

## Основные зоны кода
- `backend/internal/engine/`
- `backend/internal/repository/`
- `backend/internal/domain/recap/`
- `backend/internal/api/dto/`
- `frontend/src/features/recap-action/`
- `frontend/src/widgets/RecapOverlay/`
- `frontend/src/shared/ui/Modal/`

Это не полный production-репозиторий, а подборка файлов с фокусом на моём вкладе.
