# Yearly Recaps Service

Этот репозиторий содержит файлы, где мой вклад был основным.

## Полный список направлений, над которыми я работала

Я занималась серверной частью фичи «годовой recap» — логикой, которая собирает активность пользователя за год и превращает ее в понятную историю.
По сути, моя работа была про то, чтобы из сырых данных (просмотры, поиски, избранное, сделки, объявления, сообщения) собирать готовый результат для фронтенда:
- определять роль пользователя за год (покупатель / продавец / наблюдатель);
- выбирать самые релевантные метрики и формировать текст для карточек recap;
- подбирать достижения (ачивки) по поведению пользователя;
- выбирать одно рекомендуемое действие на основе активности пользователя (что лучше сделать дальше);
- формировать для этого действия нужный target с данными объявлений (категория, название, цена, фото, статус, просмотры и т.д.).

Также я дорабатывала структуру бэкенда под этот процесс:
- разделяла доменную логику, сбор метрик, генерацию recap и API-слой;
- приводила контракты ответа к стабильному формату, чтобы фронтенд получал единые поля;
- обновляла seed-данные и сценарии, чтобы можно было тестировать разные типы пользователей и разные действия;
- поддерживала тесты и проверяла, что после изменений логика работает предсказуемо.
